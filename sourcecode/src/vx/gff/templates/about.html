Graphs From Features (GFF+) — User Guide & About

Interactive Feature Graph, Subspace Projection, Explainability (XAI), and Multimodal Point Explorer
GitHub Repository Original Paper (DOI)
1. Upload Dataset & Select Any Target
  • Upload any .csv or .zip dataset from the Datasets screen.
  • Select any column (class label, health condition, clustering ID, or numeric target) in the TARGET dropdown, then press to update the feature graph or projection.
2. Live Feature Selection & Layouts
  • Drag the left color threshold bar or the XAI threshold slider for real-time feature selection with live / SELECTED: X / Total updates.
  • Switch between 8 feature layouts (Force, Bundle, Sunburst, Pack, Heatmap, Community, Bipartite, UpSet) or filter features by name with the blue Filter button.
3. Pan, Zoom & Keyboard Shortcuts
  • Click the Hand button () or hold Ctrl (or Space) while dragging to pan either canvas smoothly.
  • Use the mouse wheel or + / − / Reset buttons for constant-step zooming.
  • Hold Shift + drag on the projection to brush Group B for contrastive comparison.
4. Multimodal Point Data Explorer
  • Attach local files, a folder, or upload a persistent media .zip (images, audio with waveform, video, PDF, or searchable text documents).
  • Click any projected point to inspect its attached media. If no media is attached, GFF+ shows the original instance's full feature names & values plus its nearest projected neighbors.
5. Contrastive & Counterfactual Subspace Inspector
  • Lasso a cohort (Group A) on the projection — and optionally Shift+lasso Group B — to compute local contrastive drivers (Cohen's d, Welch t-test, Benjamini-Hochberg FDR) in the bottom dock.
  • Hover or click candidate features to preview counterfactual subspace perturbations and quality deltas.
6. VisPipeline Exports & Full-Fit Screenshots
  • Export VisPipeline-compatible .prj (automatically preserving CSV filenames with extensions) and .data files.
  • Use the PNG screenshot button () on any canvas, Contrastive Inspector, or Point Files viewer — or click Screenshot All in the top bar for one combined full-fit snapshot.
